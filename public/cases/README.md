# Фотографии клинических случаев

Кладите сюда снимки «до и после». Компаратор в `components/BeforeAfter.tsx`
поддерживает два формата, они задаются в `lib/data.ts` у нужного кейса:

- `collage: "/cases/ret1.jpeg"` — один файл, где слева состояние «до»,
  а справа «после». Ползунок открывает соответствующую половину.
- `photos: { before: "/cases/x-before.jpg", after: "/cases/x-after.jpg" }` —
  два отдельных снимка.

Если файл отсутствует или не загрузился, компонент автоматически показывает
рисованную иллюстрацию — раздел не ломается.

Рекомендации: горизонтальный кадр около 16:11, ширина от 1600 px, JPEG или
WebP. Next.js сам отдаст AVIF/WebP нужного размера.
